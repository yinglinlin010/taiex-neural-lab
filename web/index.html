試算一次梯度下降

改變合成例子的權重、梯度與學習率，觀察 W新 = W − η × 梯度。這是單次算式，不代表模型訓練結果。

合成目標 W=1，損失定義為 L=(W−1)²；此練習不連接模型或市場資料，也不代表訓練收斂。

比較 ReLU 與 Sigmoid 的局部梯度

調整輸入 z 與目標 y，並列 ReLU 與 Sigmoid 在相同平方損失下的梯度，觀察 Sigmoid 在較大正負輸入時如何飽和。

z=0 的不可微點採用框架次梯度慣例；此算例不連接模型或市場資料。

按實際方向比較幅度誤差

輸入成對的合成預測與實際報酬，用逗號分隔；各位置配成一筆樣本。比較實際上漲、下跌組的 MAE、零報酬基準，並並列平均絕對預測與實際幅度。

方向錯置仍留在實際方向組；零報酬列不列入上漲／下跌組。僅為合成算例，真實模型需使用一般 OOF 預測，這不是品質證據。

試算單一神經元前向傳播

輸入 x 經過權重與偏置，先算 z = wx + b，再以 ŷ = ReLU(z) 得到輸出；同時觀察 ReLU 的局部梯度是否能通過。

z>0 時 ReLU′(z)=1；z≤0 時本互動顯示局部梯度 0。這是合成的單一神經元算式，不連接訓練模型或市場資料。

試算兩個輸入匯入同一神經元

每個輸入各自乘上權重，再加總偏置：z = w₁x₁ + w₂x₂ + b；接著套用 ReLU。

試把 x₁ 加倍為 4，其他欄位不變：合成目標 y 同時由 1 調成 2，讓 δ 維持 −0.40；z 由 0.80 變成 1.80，∂L/∂w₁ 由 −0.80 變成 −1.60，∂L/∂w₂ 則維持 −0.40。因為 ∂L/∂wᵢ=δxᵢ，輸入越大，同一個 δ 會帶來越大的該權重梯度。

此互動示範 ReLU 單筆平方損失與權重／偏置梯度；文字中的 x₁ 加倍為合成敏感度例，不連接訓練模型或市場資料。

改變中心預測與誤差尺度，查看中心值上下各一個尺度的示意範圍；尺度越大，區間越寬。

試算多輸入神經元的一次更新

沿用兩個輸入神經元，設定目標與學習率。梯度由目前前向結果計算，再更新 w₁、w₂、b，並比較一階損失預測和更新後的實際合成損失。

一階預測 L(θ)+∇L·Δθ 是局部線性近似；更新後損失會重新計算。合成單筆算例不連接模型訓練或市場資料。

用有限差分核對反向傳播

沿用上方的兩輸入神經元與目標；把一個參數分別加上、減去 ε，計算中心差分並和解析梯度並列。

這是合成單神經元的數值核對，不參與模型訓練。若擾動跨過 ReLU 的 z=0 折點，中心差分不一定等於採用的次梯度。

試算四筆梯度平均後更新一次

輸入目前權重、四筆樣本各自的梯度與學習率；比較平均與直接加總、方向抵銷比例、單筆樣本對平均的最大影響，以及同一批樣本加倍時的差別。結果也固定這四筆梯度，比較完整 batch 一次更新與兩個 mini-batch 連續更新。

合成算例；不連接實際模型訓練或市場資料。

調整動量參數，觀察連續三步更新

第一步計算速度與權重；第二步沿用第一步速度，觀察歷史方向如何持續影響更新。第三步可觀察梯度反轉後，速度與權重是否立即反向；結果並列目前設定、β=0 與 β=0.5 的逐步權重。

觀察動量速度與新梯度的方向

選擇二維或三維，觀察速度在梯度方向上的投影。方向餘弦接近 1 表示同向、接近 0 表示垂直、接近 −1 表示反向；方向相反時，歷史速度會抵銷本步梯度。夾角比較的是方向；把任一非零向量放大或縮小正倍數，角度不變。

方向比較是合成向量算例；動量仍須依完整訓練與驗證結果評估，不代表模型品質。

比較 Sigmoid、ReLU 與 Tanh

共用同一個合成輸入 z 和目標 y，比較輸出、平方損失與局部梯度；小損失梯度也不保證更新後損失會下降。

Sigmoid 只會輸出 (0,1)，Tanh 只會輸出 (−1,1)，ReLU 輸出 [0,∞)；結果會標示目標是否可由該 activation 達到。平方損失為 (f(z)−y)²，平方損失梯度為 2(f(z)−y)f′(z)；飽和區的非零微小導數會用科學記號顯示；合成示例不連接模型訓練。

試算梯度裁剪

當梯度絕對值超過上限時，將它限制在正負上限內，再計算一次權重更新。

試著把上限改成 0、0.5、1 和 4：較小的上限會保留更少原始梯度，更新步幅也會縮小；上限達到原始梯度大小後就不再改變。

多參數：整個梯度向量一起縮放

範數裁剪把所有分量乘上同一比例，所以保留梯度方向；逐分量截斷則各自限制大小，可能改變方向。下方會並列兩種方法的結果。

三個參數也用同一比例

觀察三維向量各分量如何一起縮放；可驗算裁剪前後的分量比值。

四個參數：比較兩種裁剪

用相同的四維梯度和上限並列範數裁剪與逐分量截斷，檢查整體方向和各分量是否保留。

保留比例 = |裁剪後梯度 ÷ 原始梯度|；原始梯度為 0 時定義為 100%。合成算例，不連接模型訓練；裁剪不保證損失下降或預測變好。

比較合成梯度的一次 SGD 與 Adam 更新

Adam 會累積梯度平均 m 與平方梯度平均 v，再以步數 t 校正初期偏差。

固定初始參數 w₀=1、m₀=v₀=0、ε=10⁻⁸。觀察不同梯度大小：第一步 Adam 的偏差校正會抵銷梯度尺度，純 SGD 的位移則隨梯度成比例變化。這是單步合成算術，不連接模型訓練或市場資料。

讓第二步梯度反向，觀察 Adam 的動差記憶

用相反方向的合成梯度，比較 SGD 直接使用當步梯度，與 Adam 延續前一步動差後的更新。β₁ 控制有號梯度的歷史記憶；β₂ 控制平方梯度尺度的歷史記憶，可分別調整並讀取兩者對更新方向與分母的影響。

固定 w₀=1、m₀=v₀=0。ε 加在 √v̂ 的分母；梯度序列是合成算例，不連接訓練或市場資料。

分開看資料梯度與 L2 懲罰

使用合成資料損失 Ldata=(w−1)² 和懲罰 λw²。總梯度是 2(w−1)+2λw，再用一次 SGD 更新權重。最低點 w*=1/(1+λ)：λ=0 時仍是資料目標偏好的 w=1；λ>0 時最低點往零移動，結果會列出最低點的資料損失、懲罰與合計。臨界學習率為 η*=1/(1+λ)：低於它時誤差收縮，等於時等幅反號，高於時誤差放大；有號誤差倍率為 1−2η(1+λ)，可直接看出每步距離如何縮小、反向或放大。結果也會按目前 λ 比較臨界值的 0.5、1、1.5 倍，觀察誤差縮小、等距反向與放大。先比較兩項損失占比，再看各梯度對總梯度的有號貢獻率；貢獻率可為負數或超過 100%，表示兩項梯度彼此抵銷。總梯度為零時比例未定義。抵銷判斷以梯度相對大小比較，讓微小數字也能正確辨認。

掃描微小梯度的抵銷比例

保持資料梯度 2×10⁻¹³，改變反向的懲罰梯度比例，分辨誰主導合力。

練習：兩項損失方向相反時，總目標如何變化？

此合成例中資料損失下降、L2 懲罰上升。請比較兩項變化量的絕對值，再判斷總損失升降。

分開看資料損失與總損失的升降：一步降低其中一項，不保證另一項也降低。此單一參數合成例子不連接訓練或市場資料。

相同梯度下比較耦合 L2 與解耦權重衰減

固定同一個梯度 g，比較 w←w−η(g+λw) 與 w←(1−ηλ)w−ηg。權重實際更新量是 −ηg 與 −ηλw；判讀方向時須把負號一併計入。兩式在此純 SGD 更新中代數相同；輸入用來驗算等價性。

同一組輸入也會即時計算 Adam 第一步（ε=10⁻⁸）：耦合 L2 把 λw 加入梯度；解耦衰減在 Adam 梯度步外扣除 ηλw。兩者通常不等價。這是固定算例，不連接訓練或市場資料。

追蹤連續梯度下降步驟

合成損失為 L(w)=c(w−1)²，梯度為 2c(w−1)。每一步都以目前權重重新計算梯度，再用 w新=w−ηg 更新；到最低點的有號誤差每步乘上 (1−2ηc)。

結果先判讀目前輸入的 ηc 與誤差倍率：倍率絕對值小於 1 時收斂，負倍率代表越過最低點；倍率 −1 是等距振盪，絕對值大於 1 時發散。每一步列出距離、有號誤差倍率及權重位移 Δw：負梯度不代表權重必然下降，因更新式是 w新=w−ηg；梯度正時權重下降，梯度負時權重上升。比較區固定同一起點與步數，分別用 η=0.25、0.5、1 更新；提高 c 可能使同一學習率由收斂轉為振盪或發散。僅為合成數學練習，並非模型訓練結果。
