# Sequence-first 介面完整規格

**規格來源：** `.impeccable/mocks/sequence-first.png`（1504 × 1046 px）  
**介面模式：** Operate。使用者在同一工作台完成資料檢視、網路設定、訓練與驗證。  
**本專題實際資料：** TAIEX 日收盤指數快照，2010–2025；不含個股、OHLC、成交量。  
**規格優先序：** 保留參考圖的資訊架構、視覺層級和密度；所有名稱、數字、圖表與互動必須來自目前產品真實能力。

## 1. 介面目的

使用者打開工作台後，應能在一個視窗內快速回答四件事：

1. 使用什麼資料、預測什麼、資料分成哪些時間區間？
2. 神經網路接收哪些特徵、經過哪些層、輸出什麼？
3. 模型如何收斂，與基準方法相比如何？
4. 當前顯示的是驗證結果還是鎖定測試結果，下一步能做什麼？

主要行動是「訓練模型」。最終測試是獨立且一次性的後續操作，不與調參流程混在一起。這是學習和研究工具，不得用介面暗示投資績效或買賣建議。

## 2. 畫面格局

### 2.1 參考視窗與全域網格

- 基準視窗：**1504 × 1046 CSS px**；桌面版所有主內容、指標與主要操作需在此高度內同時可見。
- 頁面分成固定側欄與主工作區。側欄寬 **210 px**，主工作區從 x=210 px 開始，左右內距約 13–18 px。
- 主工作區採 12 欄概念網格，欄間距 10–13 px，面板使用相同基線與間距。
- 垂直分成四帶：頂端工具列約 48 px；條件列約 90 px；主要分析列約 502 px；結果列約 298 px；底部來源與操作列約 54 px。實際高度依視窗高度縮放，但不得讓面板彼此覆蓋。
- 桌面基準畫面不使用整頁垂直捲動。視窗低於基準高度時，優先縮減圖表留白與面板內距，仍維持可讀字級、可操作控制與主要結果；若設備高度不足以同時展示所有內容，讓主工作區自然捲動，不能裁切文字或控制。

### 2.2 固定側欄（x=0–210）

自上而下排列：

1. **品牌區**：青綠色波形標記、中文名稱「序列觀測站」、小型英文副標 `MARKET SEQUENCE LAB`。
2. **定位短句**：「用資料理解時間，用模型探索未來」。
3. **主導覽**：研究工作台、資料探索、模型實驗、模型驗證、資料庫、使用指南。每項有線性圖示；目前區域以淺青綠底和較深字色標示。
4. **專題說明卡**：簡短說明研究用途及非投資建議限制，提供研究方法連結。

側欄固定於視窗左側。小螢幕收成窄圖示列；目前項目仍須有可辨識標記，並以 accessible name 保留文字名稱。

### 2.3 頂端工具列

- 位於主工作區最上方，高約 48 px，底部細分隔線。
- 左側顯示目前所在工作區及頁面名稱；右側為「使用說明」、「文件」與設定圖示。
- 設定圖示提供進階參數入口，不取代畫面上的主要訓練行動。

### 2.4 資料與預測條件列

- 單列白色圓角卡片，基準高度約 90 px，含五個欄位，由左至右：資料標的、預測目標、資料期間、取樣頻率、進階設定。
- 欄位標題使用較深色半粗字；欄位值放入淺邊框控制或靜態讀值。
- 目標選項支援 1、5、20 個交易日報酬率；提供短提示說明「預測報酬率，不是價格點位」。
- 資產目前固定顯示 **TAIEX 臺灣加權股價指數**。不得顯示或偽裝成參考圖中的 `2330.TW`。
- 期間由載入資料的實際日期決定；頻率固定標示日資料／交易日。
- 「進階設定」展開模型與訓練參數，含回看區間、特徵、epoch、batch size、seed、learning rate、dropout、loss、optimizer、循環層數、MLP 層寬、簡單／對數報酬率。改動後需立即顯示舊驗證已過期。

### 2.5 主要分析列：時間序列與網路架構

兩個白色面板水平排列，使用約 **1.76 : 1** 欄寬比例，間距 10 px，等高約 502 px。

#### A. 收盤指數與資料切分（約 62% 欄寬）

- 面板標題在左上；右上放資料切分顯示切換及「收盤指數（原始值）」讀值。
- 圖上方以藍、綠、橘三段標示 Train、Validation、Test。
- 中央為 TAIEX 收盤指數折線圖；橫軸為日期、縱軸為指數點數。資料期間與刻度須依目前資料實際範圍產生。
- 圖底再以時間帶標出三段起迄日期。此區不得放入不存在的成交量柱、個股 OHLC 或調整後股價。
- 面板底部用小字說明 expanding walk-forward 驗證，以及最後 20% 鎖定測試期間不參與選模。
- 指標、tooltip 和日期資訊均由實際序列回應；若資料載入失敗，呈現錯誤與重試，不保留舊日期造成誤解。

#### B. 模型架構（約 38% 欄寬）

- 標題左側顯示目前模型與訓練狀態；右側選 MLP、RNN、LSTM 或 GRU。
- 標題下方摘要輸入特徵數、層數／狀態維度、dropout 及輸出維度。
- 左半欄為可勾選輸入特徵清單；只列出目前後端實際能計算的特徵：單日、5 日、20 日累積報酬及 5 日、20 日波動度，皆由收盤指數推導。
- 右半欄為即時更新的神經網路示意圖。節點數是結構示意，層數、維度、輸入／輸出必須與當前設定一致；不得把示意節點數冒充全部參數量。
- 面板底部以三格小型公式列顯示輸入張量形狀 `X ∈ ℝ^(lookback × feature_count)`、預測目標公式、損失函數。
- 底部提供「查看計算步驟」連結，通往 NumPy 小型 MLP 前向傳播、反向傳播與 PyTorch autograd 核對教學。這是數學教學範例，需與正式訓練中的 RNN/LSTM/GRU 區分。

### 2.6 結果列：三張並排卡片

由左至右欄寬約 **1.02 : 0.98 : 0.58**，間距 10 px，基準高度約 298 px。

#### A. 模型訓練與驗證損失

- 標題、說明 tooltip、MSE/log-scale 的 epoch 折線圖與圖例。
- 訓練損失及驗證損失使用不同顏色；橫軸為 epoch、縱軸為 loss。
- 尚未訓練時保留軸線和圖例，在圖中央顯示空狀態說明及「訓練模型」下一步；不得繪製假曲線。

#### B. 基準模型比較

- 標題明確標示資料集為「驗證集」或「鎖定測試集」，不得混用。
- 群組長條以 MAE、RMSE 兩種色彩比較歷史平均、零報酬、Ridge、Random Forest 及目前神經網路。
- 顯示值必須來自同一切分和當次模型工作。未完成計算時顯示空狀態，不放示意分數。
- 螢幕寬度變窄時，模型標籤可換行，但不可互相重疊；可用 tooltip 提供完整名稱。

#### C. 評估指標

- 表格列出 MAE、RMSE、R²、Spearman 相關係數、方向準確率。
- 明示指標所屬驗證折彙總或最終測試，並以目前實際數值更新；負 R² 必須照實顯示。
- 卡片底部為鎖定測試狀態與唯一一次測試按鈕。只有模型與設定已凍結、驗證有效且測試尚未執行時可操作。
- 執行後持久化狀態並鎖住按鈕；不可重新執行或用該分數回頭調參。

### 2.7 底部來源與主要操作列

- 橫跨主工作區，約 54 px 高；左側呈現資料庫圖示、來源名稱、資料快照標記及簡短用途聲明。
- 右側突出青綠色「訓練模型」主按鈕，旁為「重設設定」次按鈕。
- 訓練期間在工作台可見位置顯示工作狀態、目前折／epoch、進度和「取消訓練」。不可讓使用者只看到按鈕失效而不知原因。
- 訓練成功後顯示完成訊息；失敗／取消後說明狀態和可恢復的操作。重設不得清除已完成的鎖定測試紀錄。

### 字體與排版

- 中文：`Noto Sans TC`；拉丁介面字：`DM Sans`；數值、日期與公式：`DM Mono` 或等寬字體。
- 品牌中文約 18 px；卡片主標約 16–18 px；控制項標籤 11–12 px；輔助文字 9–11 px；公式使用 11–13 px 等寬字。
- 以字重、留白與對齊建立層級，避免過多粗體、陰影或裝飾線。
- 卡片圓角約 6–8 px，細邊框 1 px，陰影極淡。控制與表格邊界清楚，保持研究儀表板的精密感。
- 圖表使用低對比網格、清楚軸標籤、克制的青綠／藍／橘配色。所有圖例需有文字。

## 4. 元件狀態與互動契約

| 元件 | 初始狀態 | 操作後狀態與規則 |
|---|---|---|
| 資料期間 | 載入中後顯示來源實際日期 | 刷新時顯示工作中；資料雜湊變更則清除過期模型結果並提示重訓 |
| 預測期／特徵／模型參數 | 顯示已載入設定 | 任一項變更即保存草稿、更新公式與網路圖、遮蔽舊結果、停用最終測試 |
| 恢復原有設定 | 以目前設定比較驗證設定 | 若回到完全相符的設定，恢復該驗證結果有效狀態和可用操作 |
| 訓練按鈕 | 可用；參數驗證通過 | 防重複提交；工作中停用重設／資料刷新，顯示進度並提供取消 |
| 工作狀態 | 閒置 | queued/running/completed/cancelled/failed/reconnecting 各自有明確文字；連線中斷會重試查詢，不誤報完成 |
| 驗證圖表 | 未訓練空狀態 | 工作完成後以實際折資料更新；每次結果可追溯設定和資料雜湊 |
| 鎖定測試 | 有效驗證且未使用時可用 | 一次提交；結果落盤後永久標示已使用；不提供重跑按鈕 |
| 重設 | 可用 | 回預設值並清理當前草稿；若存在工作則不可操作；不可刪除持久化測試紀錄 |
| 錯誤訊息 | 隱藏 | 置於相關控制附近或明顯狀態區，描述原因與可行修復，不只顯示原始例外 |

## 5. 資料、模型與文案真實性

1. 原始序列只代表 TAIEX 每日收盤指數；不可把收盤指數標成股票價格、調整後價格或 OHLC。
2. 不可展示參考圖中的 `2330.TW`、台積電、成交量、成交量加權比率、移動平均、RSI、MACD 或 Momentum 為本專題可選資料，除非資料來源與後端計算已實際新增並經驗證。
3. 目前五個可用特徵為 `return_1`、`return_5`、`return_20`、`volatility_5`、`volatility_20`；UI 清單、張量維度和訓練 API 必須一致。
4. 目標為指定期的簡單報酬率 `C[t+h]/C[t] - 1` 或對數報酬率 `ln(C[t+h]/C[t])`，不是未來價格。
5. 對照基準名稱須與後端結果吻合。若實際是 Random Forest，不可在畫面標「隨機森林（RF）」但未運算；不可把歷史平均或零報酬結果換成圖上示意數字。
6. expanding walk-forward 驗證與最後 20% 鎖定測試需明確分離；每折只以該折訓練資料 fit 標準化參數，避免未來資料洩漏。
7. 指標顯示值必須和當次資料集、設定、切分相符。教學示例需標「教學用例」，不得與正式訓練結果混淆。
8. 使用者可看到資料日期、來源、筆數、雜湊或等效識別資訊，以及樣本有限和非投資建議說明。

## 6. 響應式與鍵盤可用性

- **桌面 ≥ 1400 px**：使用參考圖三欄主構圖，基準 1504 × 1046 一屏完整呈現。
- **平板／中型桌面 901–1399 px**：側欄縮窄，時間序列與網路面板堆疊；結果卡片重排，操作列固定或跟隨視窗，不能遮住內容。
- **手機 ≤ 600 px**：窄圖示側欄，控制列採單欄／雙欄流動排版，圖表與網路圖縱向排列，結果卡片單欄；不允許水平溢出。訓練和取消操作必須可見且可觸控。
- 互動目標至少 40 × 40 px（除密集表格中的非互動文字外）；鍵盤可達所有控制、連結和摘要列。
- Tab 焦點使用清楚可見的高對比外框；checkbox/select/input 具關聯標籤；圖表有文字替代描述；動態狀態用 `role=status`／live region 回報。
- 禁用按鈕需同時提供原因或正在處理中的狀態；不能僅靠灰色表示。
- 尊重 `prefers-reduced-motion`；動畫只用於短暫狀態過渡，不影響資料讀取。

## 8. 與示意圖的刻意差異

本規格完整沿用示意圖的研究工作台架構與視覺層級，但保留專題資料真實性。因此，不能照搬示意圖中的個股選擇器、調整後股價、成交量、額外技術指標、Random Forest／Ridge 實際結果或其假數字。若要新增這些資料與方法，需先完成資料契約、計算定義、時間對齊、後端實作與洩漏檢查，再擴充介面規格。
