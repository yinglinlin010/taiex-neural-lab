# 神經網路股價預測｜學習地圖

```text
TAIEX 收盤序列
  → 建立因果特徵與預測標籤
  → 按目標日期做時間切分與 purge
  → 設定 MLP / RNN / LSTM / GRU
  → PyTorch 前向傳播、損失與反向傳播
  → expanding walk-forward 驗證與基準比較
  → 凍結一組設定，最後 20% 鎖定測試一次
  → 用 NumPy 手算一個 MLP 更新並對照 autograd
  → 整理實際結果、限制與報告
```

| 站點 | 操作 | 需要理解 | 完成證據 |
|---|---|---|---|
| 1. 資料 | 看資料期間、欄位與雜湊 | 交易日、資料快照、收盤指數 | 說明本機有什麼和沒有什麼 |
| 2. 特徵 | 選 lagged returns、波動度與回看窗 | 特徵、時間窗、報酬率 | 寫出一個輸入張量的形狀 |
| 3. 網路 | 比較四種架構 | MLP 展平序列；循環隱狀態；LSTM/GRU 閘 | 解釋差異來自輸入處理與狀態更新 |
| 4. 訓練 | 調整 epoch、batch、層與 optimizer | loss、梯度、learning rate、dropout | 描述一次參數更新 |
| 5. 驗證 | 看 walk-forward 各折及兩個基準 | expanding window、purge、MAE/RMSE | 指出模型是否勝過簡單基準 |
| 6. 手算 | 查看 3–2–1 MLP 計算 | 鏈鎖律、梯度、SGD 更新 | NumPy 與 PyTorch 梯度差接近機器精度 |
| 7. 鎖定測試 | 選定一個模型設定後只跑一次 | 模型選擇與測試集隔離 | 報告中標示測試已使用且不再調參 |

專題涵蓋一個小型時間序列神經網路實驗，不等於學完金融機器學習或建立可交易策略。結果只適用於這份資料、特徵和評估協定。
